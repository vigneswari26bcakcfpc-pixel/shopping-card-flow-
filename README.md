# 🛍️ Fashion Shopping Cart Flow

A modern and user-friendly **Fashion Shopping Cart Mobile App UI** designed in Figma.  
This project demonstrates the complete shopping journey from browsing fashion products to successfully placing an order.

## 📱 Project Overview

The Fashion Shopping Cart Flow is designed to provide users with a simple and smooth online shopping experience.

Users can browse fashion products, view product details, add items to the cart, review their cart, select a payment method, and complete the checkout process.

## ✨ Features

- 🏠 Home / Fashion Product Page
- 🔍 Product Search
- 👗 Fashion Product Listing
- 📸 Product Details
- ⭐ Product Ratings & Reviews
- 🎨 Product Color Selection
- 📏 Product Size Selection
- 🛒 Add to Cart
- ➕ Increase / Decrease Product Quantity
- 🗑️ Remove Products from Cart
- 💳 Multiple Payment Methods
- 📍 Shipping Address
- 📋 Order Summary
- ✅ Order Confirmation
- 🏡 Continue Shopping Option
